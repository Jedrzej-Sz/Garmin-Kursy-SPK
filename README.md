# Garmin-Kursy-SPK
Projekt pod hostowanie plików dla testowej aplikacji w monkey c dla garmina. Aplikacja ma bazować na tym repozytorium, a raczej na github pages aby otrzymać dane na zegarek.


Źródło danych: Swarzędzkie Przedsiębiorstwo Komunalne Sp. z o.o. (spk.swarzedz.pl). Dane są automatycznie przetwarzane do formatu JSON na potrzeby prywatnego widżetu zegarkowego; przewoźnik nie ponosi odpowiedzialności za ewentualne błędy parsowania.   

Projekt nieoficjalny, niezwiązany i nieautoryzowany przez Garmin International, Inc. ani SPK Swarzędz.
